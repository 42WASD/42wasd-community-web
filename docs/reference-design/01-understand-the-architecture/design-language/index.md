# Design language

Design language is **independent** from MVU architecture. The visual theme
should not dictate state ownership.

## Developer-community direction

```text
minimal
clean typography
strong spacing
neutral surfaces
subtle borders
dark/light theme
small accent palette
accessible contrast
simple cards
```

## Gaming-community direction

```text
dark-first
stronger artwork
larger hero imagery
accent lighting
server-status indicators
tournament cards
controlled glass/overlay surfaces
```

> Do not let the visual theme dictate state ownership. The architecture stays
> the same regardless of which design direction you choose.
