# Reference applications to study, not blindly fork

Use as architecture donors:

```text
Dapr Quickstarts
    current APIs and building blocks

Azure-Samples/dapr-store
    gateway + multiple services + state + pubsub + auth patterns

Dapr Traffic Control
    broader Dapr building-block composition

eShopOnDapr
    study distributed architecture only
    repository is archived/outdated for a new 2026 base

DeathStarBench Social Network
    study social-service decomposition/performance ideas
    benchmark system, not production starter
```

Build your own reusable `42wasd-service-template` instead of forking any of
these.
