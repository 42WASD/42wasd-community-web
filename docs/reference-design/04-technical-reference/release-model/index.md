# Release model

Release artifacts, upgrade order, contract deprecation, database growth, and
NVMe cache capacity expectations.

## Subsections

- **Release artifact** — pinned platform release record.
- **Upgrade order** — ordinary vs platform-component upgrades.
- **Contract deprecation policy** — current + previous window.
- **Database growth policy** — thresholds and actions.
- **NVMe cache capacity expectations** — accelerator, not limit.
