# Browser scope model

The route-scope model, lifecycle state machine, query keys, and coordinator
policy for the browser.

## Subsections

- **Browser route-scope model** — `DataScope` DU and the active/inactive rule.
- **Route lifecycle state machine** — INACTIVE → LOCAL_LOADING → ... states.
- **Query key convention** — stable semantic keys.
- **RequestCoordinator policy** — priorities, cancel rules, mutations.
