# Acceptance tests

Functional acceptance, performance acceptance, load-test scenarios, upgrade
matrix, and disaster matrix.

## Subsections

- **Platform functional acceptance test** — the nine-group production-release
  checklist (client caching, request coordination, PWA/versioning, database,
  cache, realtime, messaging, media, auth, storage, Cilium, GitOps).
- **Performance acceptance test** — benchmark the full stack before "done".
- **Load-test scenarios** — the eight minimum scenarios.
- **Upgrade test matrix** — client/IndexedDB/DB/proto skew.
- **Disaster test matrix** — intentional failure drills.
