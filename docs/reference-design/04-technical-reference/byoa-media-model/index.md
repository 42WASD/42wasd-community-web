# BYOA media model

The MediaRef contract, upload state machine, YouTube client rules, and
external media rendering security.

## Subsections

- **BYOA MediaRef contract** — provider-neutral identity in the DB.
- **BYOA upload state machine** — LOCAL_SELECTED → AVAILABLE states.
- **YouTube upload client rules** — code model, memory, resumability.
- **External media rendering security** — allowlists, no raw embeds.
