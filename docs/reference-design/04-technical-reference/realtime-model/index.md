# Realtime model

Subscription identity, event envelope, delta synchronization, pagination, and
prefetch policies.

## Subsections

- **Realtime subscription identity** — narrow groups, authorization to join.
- **Realtime event envelope** — EventId/Scope/Sequence metadata.
- **Active-scope delta synchronization API** — cursor-based change protocol.
- **First-load pagination policy** — viewport-sized first projections.
- **Client prefetch policy** — only high-probability adjacent data.
