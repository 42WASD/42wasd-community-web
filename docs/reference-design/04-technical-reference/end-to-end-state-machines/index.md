# End-to-end state machines

The eight complete flows from user action to durable effect.

## Subsections

- **End-to-end forum read** — scope activation through the cache stack.
- **End-to-end realtime mutation** — commit → outbox → fanout.
- **End-to-end reconnect** — cursor repair after network loss.
- **End-to-end rapid navigation** — coordinator reuse/cancel.
- **End-to-end cache miss** — L1 → L2 → origin → populate.
- **End-to-end queued command** — JobId owns the lifetime.
- **End-to-end BYOA video** — browser → provider directly.
- **End-to-end external account login** — provider subject → Account → Persona.
